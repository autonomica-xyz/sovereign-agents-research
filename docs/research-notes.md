1 Keys: NEAR MPC https://github.com/near/mpc (prod); Lit PKP https://developer.litprotocol.com/ (prod); dstack KMS https://github.com/Dstack-TEE/dstack https://arxiv.org/abs/2509.11555 (prod, TDX-centric); RSS threshold sigs in SEV-SNP+TDX https://eprint.iacr.org/2026/1670 (research; no attestation-bound shares/rollback/BFT); TeeDAO https://arxiv.org/abs/2606.04912 (SGX/TDX/Hygon); FROST RFC 9591; CMP https://eprint.iacr.org/2020/492; Liquefaction key encumbrance https://arxiv.org/abs/2412.02634 (prototype); iO JLS https://arxiv.org/abs/2008.09317, Machina Diamond iO https://machina-io.com/posts/hello_world_first.html (depth0 15.8min/34.3GB/6.3GB; depth10 129min/225GB); witness encryption theory only. ## Part 2 (complete)
4 cont. Rollback/fork: ROTE; Narrator ~6k updates/s on 5 nodes https://github.com/pw0rld/narrator; Nimble OSDI23 https://www.usenix.org/conference/osdi23/presentation/angel. None can prove the old copy was destroyed; only a quorum or ledger that refuses the second copy prevents running twins. One-time programs via counter lockboxes https://eprint.iacr.org/2022/1257.
5 Funding: Lightning agent tools https://github.com/lightninglabs/lightning-agent-tools https://lightning.engineering/posts/2026-02-11-ln-agent-tools/ ; L402 https://docs.lightning.engineering/the-lightning-network/l402 ; Cashu NUTs https://github.com/cashubtc/nuts ; Fedimint https://fedimint.org ; NWC NIP-47 https://github.com/nostr-protocol/nips/blob/master/47.md ; Alby MCP https://github.com/getAlby/mcp ; Routstr https://routstr.com ; PayPerQ https://ppq.ai. Gap: no published full loop of earn -> buy TEE/GPU -> redeploy; mints and federations are custodians.
6 ALife: Tierra; Avida https://github.com/devosoft/avida ; POET https://arxiv.org/abs/1901.01753 ; AI-GAs https://arxiv.org/abs/1905.10985 ; OMNI https://arxiv.org/abs/2306.01711 ; Open-endedness for ASI https://arxiv.org/abs/2406.04268 ; Sakana ASAL https://arxiv.org/abs/2412.17799 ; AI Scientist https://arxiv.org/abs/2408.06292 https://arxiv.org/abs/2504.08066 ; Darwin Godel Machine https://arxiv.org/abs/2505.22954 (SWE-bench 20->50%). Gap: none connect agents to real keys or money; all run in sandboxes.
Dead ends: trusting a single TEE vendor (TEE.fail https://tee.fail, Battering RAM, WireTap, SGX.fail); iO/witness encryption as a key vault today; zkML at 70B; migration or proof of deletion as anti-cloning (needs a quorum or ledger); treating attestation as proof a host is safe.
Claims: Phala post-mortem confirmed https://phala.com/posts/2026-10-post-mortem-dstack-guest-agent-vulnerability (8-12 Oct; /logs endpoint; env vars; gateway admin token; fixed in v0.6.1/v0.5.12; Phala's own findings). confidentialinference.net 0/13 confirmed (live).
