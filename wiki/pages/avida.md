# Avida

> A digital-evolution platform (Ofria, Adami, Brown, 1990s) where
> self-replicating programs compete for CPU time on a virtual grid and are
> rewarded for performing logic tasks. It produced classic results on how
> complex features evolve.

## Details

- Organisms are instruction sequences that copy themselves with mutation.
- Rewards ("merit") for computing functions such as EQU give more CPU cycles.

## How it serves the organism

The original model of the [earn-buy-redeploy-loop](earn-buy-redeploy-loop.md):
do useful work → earn CPU → replicate.

## How it fails

Closed world; no hostile hosts or money.
