# ADAS

> Hu, Lu and Clune (2024) had a "meta agent" write new agents in code,
> keeping an archive of previous designs (Meta Agent Search). Discovered
> agents beat hand-designed ones and transferred across domains and models.

## Details

- Agents are defined as Python code, so the search space is all possible
  agent designs.
- Precursor of the Darwin Gödel Machine by overlapping authors.

## How it serves the organism

An organism can design its own children's architectures, not just copy
itself.

## How it fails

Search cost; evaluation on benchmarks rather than survival.
