# exo

> Open-source software (exo labs) that clusters ordinary devices, mainly
> Macs, into one inference machine with automatic peer discovery and tensor or
> pipeline parallelism, including RDMA over Thunderbolt 5. About 48.6K GitHub
> stars; v1.0.71 (Apr 2026); repo active Nov 2026.

## Details

- Runs models too large for any single device by splitting them.
- Local network focus; not designed for strangers on the internet.

## How it serves the organism

Lets a few cheap or scavenged machines in one place act as one body
large enough for a capable model.

## How it fails

Assumes trusted LAN peers; Apple-centric performance.
