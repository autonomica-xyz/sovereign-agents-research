# Urbit

> A personal server OS where identity (a "ship" such as ~sampel-palnet) is an
> NFT-like asset on Ethereum, and all networking is between identities, not IPs.
> Each ship is a deterministic, event-sourced computer whose state can be
> moved between machines.

## Details

- Event-log design means the whole state is a replayable log, which is a
  form of [rehydration](rehydration.md).
- Hierarchical identity: galaxies sponsor stars, stars sponsor planets.

## How it serves the organism

A portable, key-owned computer identity that can move hosts.

## How it fails

Sponsors can stop routing; small ecosystem; performance limits for AI
workloads.
