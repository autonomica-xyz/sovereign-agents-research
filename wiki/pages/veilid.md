# Veilid

> A peer-to-peer application framework released by Cult of the Dead Cow
> members in 2023: private routing, a distributed hash table and node
> identities by key, written in Rust. Still pre-1.0 in Nov 2026.

## Details

- Every node relays for others, Tor-like, without exit nodes to the clear
  web.
- Designed for apps that need no servers.

## How it serves the organism

Private routing plus storage in one library it can embed.

## How it fails

Pre-1.0, small network, little auditing.
