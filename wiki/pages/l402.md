# L402

> A server answers `402 Payment Required` with a Lightning invoice and a
> macaroon; the client pays and presents the preimage as proof. Machines can
> buy API calls with no account. Lightning Labs' Aperture is the reference
> proxy.

## Details

- Tooling: Aperture (server proxy), `lnget` (client), pi402 (agent harness).
- Measured demand: Alby's l402.space proxy saw about **$40 in total** since
  July 2026; 1,990 endpoints listed, only 9% healthy (13 Oct 2026).
- Some providers expose both L402 and [x402](x402.md) on the same endpoint
  (for example TunnelSats' "Sovereign Agent Stack", Oct 2026).

## How it serves the organism

Both a way to buy (inference, data) and a way to sell its own API with no
payment processor.

## How it fails

Almost nobody pays over it yet ([op-non-token-revenue](op-non-token-revenue.md)).
The macaroon is a bearer credential: if leaked, it can be replayed until it
expires.
