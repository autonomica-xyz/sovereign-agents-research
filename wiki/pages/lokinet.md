# Lokinet

> An onion-routing network run on Session/Oxen service nodes, giving `.loki`
> addresses owned by keys and carrying any IP traffic. Still maintained in
> 2026 (v0.9.14 updated bootstrap lists for the Session Technology
> Foundation's node transition).

## Details

- Service nodes stake tokens, which sybil-protects the router set.
- Low-latency, works at the IP layer, so normal software runs over it.

## How it serves the organism

Another key-owned address network with a staked node set.

## How it fails

Depends on one ecosystem's token and foundation; small user base.
