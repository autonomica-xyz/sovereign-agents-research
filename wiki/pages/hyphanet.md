# Hyphanet

> The original Freenet (since 2000), renamed Hyphanet in 2023: an anonymous,
> censorship-resistant data store where inserted content is encrypted and
> spread across volunteers' disks. Still releasing in 2025 (0.7.5 builds
> 1502–1507).

## Details

- Popular content survives; unpopular content decays.
- "Darknet" mode connects only to known friends.

## How it serves the organism

Anonymous publication of code or memory with no host that knows it holds
it.

## How it fails

Slow; content not requested fades; small network.
