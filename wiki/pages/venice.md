# Venice

> A private AI inference service (founded by Erik Voorhees, 2024) whose
> private tier promises zero data retention on Venice-controlled machines.
> Its tokens make compute an asset: staking VVV can mint DIEM, and each
> staked DIEM gives $1/day of API credit indefinitely.

## Details

- API is OpenAI-compatible; open models and some proprietary ones.
- Prices per million tokens, e.g. DeepSeek V3.2 $0.33 input / $0.48 output
  (Nov 2026).
- No hardware attestation: privacy is a policy, not a proof. Morpheus does
  not tag Venice-backed providers as TEE-verified.

## How it serves the organism

A crypto-native, account-light route to inference, and a way to convert a
one-time endowment (DIEM) into a permanent thinking budget.

## How it fails

Trust-based privacy; one company; DIEM value depends on Venice staying in
business.
