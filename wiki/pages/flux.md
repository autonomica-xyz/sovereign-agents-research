# Flux

> A decentralised cloud (formerly ZelCash, 2018) where staked node operators
> run containerised apps, paid in FLUX; apps are replicated across several
> nodes by default. FluxEdge adds GPU rental.

## Details

- Deployments are specified by the app owner and spread over multiple
  nodes, which gives some redundancy for free.
- No TEE by default.

## How it serves the organism

Replicated hosting it can pay for with tokens.

## How it fails

Operators can read workloads; token-dependent; small network.
