# Namecoin

> The first fork of Bitcoin (2011), built to register names (.bit) on a
> blockchain. The 2011–2013 Bitcoin agent design used it so agents could name
> themselves (`x536ma.storj.bit`). Still running but little used.

## Details

- Names must be renewed every ~36,000 blocks (about 250 days).
- Merge-mined with Bitcoin.

## How it serves the organism

Historical proof that blockchain names were part of the organism design from
the start ([bitcoin-wiki-agents](bitcoin-wiki-agents.md)).

## How it fails

Almost no resolver support; squatting; low security budget.
