# Tierra

> Tom Ray's 1991 system of self-replicating machine-code programs competing
> for memory and CPU time inside a virtual computer. Parasites, hosts and
> hyper-parasites evolved without being designed. The first "digital
> organisms" in the modern sense.

## Details

- A "reaper" killed the oldest or most error-prone programs when memory
  filled, which is selection by resource scarcity.
- Parasites evolved that used other programs' copy code.

## How it serves the organism

Shows that parasitism and defence against it appear by themselves once
programs compete for scarce compute; real organisms should expect the same
from other agents.

## How it fails

Evolution plateaued in a closed world; open-endedness needs a changing
environment.
