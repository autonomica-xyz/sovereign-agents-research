# napplet

> Nostr-native web applets: sandboxed iframes addressed by npub, with signing
> brokered by the host shell (specified as NIP-5D). Browser-only and alpha. The
> NAP spec now defines agent identity in a `SOUL.md` file.

## Details

- Runs inside a browser shell, not on a server, so it is not a body for the
  organism's mind.
- Useful as a user interface people can load from Nostr to buy the organism's
  services.

## How it serves the organism

A storefront no app store can delist.

## How it fails

Alpha, browser-only, depends on users running a compatible shell.
